# Catalyst 7 practice dashboard

The interface serves reception staff in a bright practice during the day, where appointments must be readable at a glance. Use a light theme with warm off-white canvas, pale green surfaces and a restrained deep forest-green accent, matching the approved concept.

## Visual system

- System sans-serif typography; 14px body, 12px metadata, 28px page title.
- Charcoal-green text and quiet grey-green secondary labels.
- OKLCH tokens in public/dashboard/dashboard.css define colours and state roles.
- Fine dividers, generous page margins, compact calendar controls, 8–12px corner radii.
- Sidebar navigation, a central calendar and a contextual activity rail.
- Appointment detail drawer, readable inbox, responsive navigation.
- Green for current selection and confirmed bookings, amber for attention, muted rose for cancellation.
- Icons use a consistent 24px line grid. Status always includes text.
- Short state transitions only; respect reduced motion.

## Demonstration and pilot data

The default dashboard contains fictional local demonstration data. Demonstration actions affect that browser tab only. The protected pilot connection is read-only and labelled separately. No service credentials or contact numbers belong in the interface.
